= Atina JDE EnterpriseOne — Partner Connector - Release Notes
:keywords: JDE, JDEdwards, EnterpriseOne, Oracle, JD Edwards, ATINA
:toc:
:toclevels: 1

The Atina™  JDE EnterpriseOne — Partner Connector enables native integration between Boomi™ and Oracle JD Edwards EnterpriseOne™ through the Atina JDE Microservice. The connector provides a simplified interface for invoking JD Edwards EnterpriseOne business logic without requiring direct communication between the Boomi Atom and the JD Edwards environment.

== Atina JDE EnterpriseOne — Partner Connector 1.0.0 - September 2026

=== Release Type

Initial General Availability (GA) Release

=== Target Platform Release:

September 2026 Runtime Release

=== Features

* Authenticate using JD Edwards credentials or an existing session token.
* Logout from a JD Edwards session.
* Discover BSFNs by name.
* Resolve BSFN metadata (signature and parameters) at runtime.
* Cache BSFN & UBE definitions locally in xml format.
* Invoke JD Edwards EnterpriseOne Business Functions (BSFN).
* Invoke JD Edwards EnterpriseOne Business Services (Web Services).
* Manage transactions for BSFN (Start, Commit, and Rollback).
* Invoke a UBE by name / version. It allows use of data selection using SQL syntax
* Retrieve UBE Job Status.
* Poll MBF Events transactions.
* Invoke Web Services
