# Atina JDE Connector

The **Atina JDE Connector** provides seamless interoperability with **Oracle’s JD Edwards EnterpriseOne™**, enabling direct and efficient integration between JDE and the wide range of APIs, SaaS, Enterprise, and Legacy systems supported by **MuleSoft’s Anypoint Platform**.

The connector can be easily dropped into any Mule flow to connect JDE data and processes with your enterprise ecosystem, ensuring high performance, security, and reliability.

The Atina JDE Connector offers comprehensive support for the full range of JDE services, including **Financial Management, Project Management, Asset Life Cycle, Order Management, Manufacturing, Mobile, and Reporting solutions**.
  
With the Atina JDE Connector, you can

- Integrate JDE with EDI/trading partners, Salesforce, POS, databases, HR, and Financial systems.
- Send data to or receive data from JD Edwards in real time or batch mode.
- Rely on a highly secure, enterprise-grade solution from a trusted JDE integration specialist.
 
Key Features

- **Direct invocation of JDE Web Services** for modern and flexible integration scenarios.
- Invoke any JDE **Business Function (BSFN)** with full parameter support.
- Submit and monitor **Universal Batch Engine (UBE)** jobs by name and version.
- Apply **Data Selection** to filter records before UBE execution.
- Pass **Report Interconnect (RI)** parameters to UBEs.
- Retrieve and track **UBE execution status**.
- Capture outbound events triggered by applications using **Master Business Functions** with Interoperability enabled.
- Capture outbound **EDI Events** generated by JDE EDI Module applications.
- Invoke multiple BSFNs within the same database transaction.
